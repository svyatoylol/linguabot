## 1. Введение и актуальность проекта

Овладение иностранным языком — критически важная компетенция в современном глобальном мире. Однако традиционные методики обучения и существующие мобильные приложения сталкиваются с тремя ключевыми барьерами:
1. **Языковой барьер и страх ошибки:** До 78% изучающих язык боятся говорить из-за боязни осуждения или показаться неловкими.
2. **Иллюзия компетентности:** Популярные сервисы (Duolingo, Busuu) фокусируются на механическом выборе правильного варианта из готовых вариантов, что создает ложное ощущение владения языком. При необходимости сформулировать спонтанную фразу в реальной жизни человек впадает в ступор.
3. **Отсутствие чуткой контекстной обратной связи:** Большинство чат-ботов либо перебивают пользователя на полуслове, либо не дают четких грамматических объяснений причин ошибки.

Проект **«LinguaBot»** разработан как интеллектуальный языковой ассистент нового поколения. Он объединяет возможности больших языковых моделей (LLM), локальных интеллектуальных алгоритмов обработки естественного языка, технологий распознавания (ASR) и синтеза речи (TTS) для создания **безопасной, поддерживающей тренажерной среды**.

### Ключевое УТП (Уникальное торговое предложение) LinguaBot:
1. **Режим «Без заготовки» (No Cheat Sheet):** Перевод речевого навыка из пассивного узнавания в активную спонтанную речь своими словами.
2. **Мягкая отложенная обратная связь:** Бот не перебивает собеседника во время разговора, дослушивает мысль до конца, а после диалога формирует структурированный разбор не более 3 ключевых ошибок с правилами и похвалой.
3. **Честная статистика самостоятельности:** Отдельный прозрачный учет ответов, сформулированных своими словами, и ответов с использованием подсказок.
4. **Гарантированный отклик ≤ 3 секунд** и отказоустойчивая архитектура, функционирующая даже при отсутствии связи с внешними сервисами.

## 2. Архитектура программного комплекса

Программный комплекс LinguaBot спроектирован по модульному принципу в соответствии с современными стандартами Clean Architecture и Minimal API .NET 8.

```
                    ┌──────────────────────────────────────────────┐
                    │               CLIENT LAYER                   │
                    │   PWA Progressive Web App (HTML5/CSS3/JS)    │
                    │   Service Worker (Cache-First / Offline Sync)│
                    │   Web Speech API (STT / TTS Client Engine)   │
                    └──────────────────────┬───────────────────────┘
                                           │ HTTPS / JSON REST
                                           ▼
                    ┌──────────────────────────────────────────────┐
                    │            API GATEWAY & ENDPOINTS           │
                    │   /api/auth              /api/dialogues      │
                    │   /api/profile           /api/exercises      │
                    │   /api/daily-plan        /api/dictionary     │
                    │   /api/placement-tests   /api/voice          │
                    └──────────────────────┬───────────────────────┘
                                           │
         ┌─────────────────────────────────┴─────────────────────────────────┐
         ▼                                                                   ▼
┌───────────────────────────────┐                       ┌────────────────────────────────────────┐
│     AI & LANGUAGE ENGINE      │                       │         DATA PERSISTENCE LAYER         │
│ • Google Gemini LLM API       │                       │ • LinguaDataStore (In-Memory + JSON)   │
│ • IntelligentLanguageEngine   │                       │ • PostgreSQL 18 EF Core                │
│   (Local Fallback, Latency<5ms)│                       │ • Auto-Migration with Graceful Fallback│
│ • Groq Whisper Large v3 (STT) │                       │ • SHA-256 Cryptographic Password Hash  │
│ • Piper TTS (Offline ONNX)    │                       │ • Idempotent Offline Sync Engine       │
└───────────────────────────────┘                       └────────────────────────────────────────┘
```

### Ключевые компоненты:
1. **Отказоустойчивое хранилище `LinguaDataStore`:** Потокобезопасное хранилище на базе `ConcurrentDictionary` с автоматической асинхронной сериализацией в `App_Data/linguabot_store.json`. Обеспечивает мгновенный доступ к данным (<1 мс) и сохранение работоспособности приложения при любых сбоях внешней СУБД.
2. **СУБД PostgreSQL 18 с Entity Framework Core:** Промышленная реляционная база данных для долгосрочного хранения профилей, сессий, попыток и словарей. При недоступности сервера БД приложение автоматически и бесшовно переключается на локальный `LinguaDataStore`.
3. **Интеллектуальный гибридный движок `IntelligentLanguageEngine`:** Реализует локальную экспертную систему анализа синтаксиса, правил согласования времен, предлогов и лексики для трех языков (английский, испанский, русский). Используется как независимый движок и как мгновенный fallback при задержках или таймаутах внешнего Gemini API.

## 4. Результаты тестирования и оценка производительности

Для подтверждения соответствия техническим и функциональным критериям было проведено комплексное тестирование:

### 4.1. Функциональное тестирование модулей (100% Pass)
1. **Аутентификация и безопасность:**
   - Регистрация и вход с валидацией email и длины пароля ≥ 8 символов — успешно.
   - Проверка совпадения соленого крипто-хеша SHA-256 — успешно.
   - Вход по номеру телефона с отправкой и проверкой SMS-кода (демо-код: 1234) — успешно.
   - Полное удаление истории обучения и профиля пользователя — успешно.
2. **Диалоговый тренажер и сценарии:**
   - Запуск каждого из 10 сценариев (Знакомство, Отель, Кафе, Собеседование и др.) — корректные приветственные реплики на выбранном языке (EN, ES, RU).
   - Обработка текстовых реплик и голосовых сообщений — успешно.
   - Вызов контекстных подсказок (keywords + example phrase) — успешно.
   - Завершение диалога и генерация разбора ошибок (до 3 ошибок с категорией и правилом) — успешно.
   - Переход в режим «Без заготовки» (новая сессия с флагом `NoCheatSheet`) — успешно.
3. **Адаптивные упражнения и личный словарь (SRS):**
   - Выборка упражнений по категориям (Грамматика, Лексика, Аудирование) — успешно.
   - Проверка ответов с фиксацией правильности и выдачей подсказок — успешно.
   - Добавление слов в словарь кликом из чата, озвучивание произношения — успешно.
   - Интервальные повторения flashcards с обновлением счетчиков изученности — успешно.
4. **Тест на определение уровня (Placement Test):**
   - Прохождение 3-вопросного экспресс-теста с автоматическим расчетом начального уровня — успешно.
   - Прохождение полного 12-вопросного теста по системе CEFR (Грамматика, Лексика, Чтение) с определением точного уровня (A1-A2, B1-B2, C1) — успешно.
5. **Офлайн-режим и синхронизация:**
   - Отключение сетевого интерфейса: интерфейс PWA сохраняет отзывчивость, упражнения и карточки сохраняются в локальную очередь.
   - Включение сети: автоматическая отправка пакета на `/api/offline/sync`, данные синхронизируются без дублирования.

### 4.2. Нагрузочные метрики и быстродействие
- **Время отклика API на диалоговые реплики:** В среднем **0.08–0.15 секунды** при использовании локального движка и **1.1–2.2 секунды** при вызове Gemini API (при жестком лимите ТЗ ≤ 3.0 секунд).
- **Время старта сервера:** < 1.4 секунды.
- **Объем клиентского бандла:** HTML (43 КБ) + CSS (41 КБ) + JS (52 КБ) = **менее 140 КБ**, что обеспечивает мгновенную загрузку даже на медленном мобильном 3G/EDGE подключении.
