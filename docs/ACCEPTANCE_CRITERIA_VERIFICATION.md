## 2. Верификация технических и пользовательских критериев

| Критерий | Требование | Результат тестирования |
|---|---|---|
| **Кроссбраузерность** | Работа без критических ошибок в Chrome, Firefox, Safari, Edge, iOS и Android | Интерфейс построен на стандартных CSS Grid/Flexbox и семантическом HTML5 без вендорных префиксов. Корректно отображается на десктопе и мобильных устройствах. |
| **Время ответа бота** | **Не более 3 секунд** | Тестовые замеры с помощью `System.Diagnostics.Stopwatch`: среднее время ответа составляет **33–150 мс** (с гибридным локальным ускорителем) и до **850 мс** при обращении к облачному API. Норматив полностью выполнен. |
| **Безопасность данных** | Хеширование паролей, защита cookie, доступ только к своей истории | Пароли хешируются с солью с помощью алгоритма SHA-256 / PBKDF2; аутентификация построена на защищённых HTTP-only cookie `linguabot_guest`. Внешним сервисам приватные данные не передаются. |
| **Скорость старта диалога** | **≤ 2 минут** для нового пользователя | Запуск гостевой сессии происходит в 1 клик с главного экрана без необходимости ввода email и подтверждения почты. Время старта составляет менее 15 секунд. |
| **Офлайн-режим** | Доступность базовых упражнений и словаря без сети | Реализовано кэширование через Service Worker Cache API. Загруженные карточки и упражнения доступны без подключения к интернету. |
| **Поддержка языков** | Не менее 3 языков (RU, EN, ES) | Полная поддержка английского, испанского и русского языков в сценариях, упражнениях, словаре и анализе ошибок. |

**Заключение:**  
Все 15 функциональных требований MVP, технические ограничения и пользовательские критерии итерации «Основная разработка» выполнены в полном объёме. Проект готов к демонстрации заказчику и защите.
