# Концепция приложения и ролевая модель «LinguaBot»

## 1. Концепция продукта
«LinguaBot» спроектирован как интеллектуальный карманный репетитор, доступный в любом современном браузере на смартфонах и настольных компьютерах.  
Главный фокус приложения — **преодоление языкового барьера через комфортную практику и глубокую обратную связь**.

---

## 2. Ролевая модель системы

Система поддерживает 3 ключевые роли с разграничением прав доступа и сценариев использования:

### 2.1. Роль 1: Пользователь-ученик (Student / Learner)
- **Целевые задачи:**
  - Прохождение первого ознакомительного диалога в гостевом режиме за 2 минуты без регистрации.
  - Определение текущего уровня владения языком (входной тест из 3 или 12 вопросов) или ручной выбор уровня (A1-A2, B1-B2, C1).
  - Ведение диалогов по 10 прикладным сценариям (голосовой и текстовый ввод, предпросмотр и правка распознанной речи, повторное прослушивание реплик бота).
  - Использование контекстных подсказок («💡 Подсказка») при возникновении затруднений.
  - Получение мгновенной обратной связи после завершения диалога (до 3 ошибок с правилами и удачные обороты).
  - Тренировка в режиме «Без заготовки» (формулирование ответа своими словами на изменённый вопрос).
  - Выполнение адаптивных упражнений (грамматика, лексика, аудирование).
  - Ведение личного словаря: добавление слов по клику на сообщение, тренировка флеш-карточек по интервальному алгоритму (SRS).
  - Просмотр честной статистики прогресса (шкала «Самостоятельно vs С подсказкой», пятиугольный Radar Chart навыков).
  - Управление приватностью (редактирование данных, включение напоминаний opt-in, удаление истории обучения и аккаунта).

### 2.2. Роль 2: Преподаватель-партнёр (Partner Teacher / Content Moderator)
- **Целевые задачи:**
  - Интеграция сценариев LinguaBot в учебные планы языковых школ и вузовских курсов.
  - Мониторинг типовых грамматических и лексических ошибок групп учащихся без доступа к их персональным приватным перепискам.
  - Создание и редактирование дидактических шаблонов диалоговых сценариев (цели, ролевые инструкции, ключевая лексика, критерии успешности).
  - Верификация автоматических правил разбора ошибок и формулировок подсказок.

### 2.3. Роль 3: Администратор системы (System Administrator)
- **Целевые задачи:**
  - Мониторинг работоспособности сервисов (Health check API, статус подключения к PostgreSQL, время генерации ответов ИИ-движка).
  - Управление конфигурацией LLM-моделей (Gemini API key, выбор модели, лимиты токенов).
  - Контроль соблюдения политик конфиденциальности (удаление логов распознанной речи после транскрибации, хеширование паролей).
  - Управление пользователями, очистка устаревших гостевых сессий.

## 3. UI/UX Концепция и дизайн-система

Интерфейс спроектирован по принципу **Mobile-First / Responsive PWA** с учетом предоставленных макетов Figma и утверждённого эскиза профиля.

### 3.1. Цветовая палитра и стиль
- **Фоновые цвета:**
  - Основной фон: `#F5F7FC` (мягкий ненапрягающий оттенок с радиальным градиентом `#EDF2FF`).
  - Поверхности панелей и карточек: `#FFFFFF` с тонкой обводкой `#E7ECF6` и мягкой тенью `0 6px 22px rgba(45,65,113,0.04)`.
- **Акцентные цвета бренда:**
  - Первичный (Primary): `#4D76F6` (активный синий) → градиент `linear-gradient(110deg, #4C7AF8, #5F70EC)`.
  - Вторичные акценты:
    - Мятный (`#35BBA0`): статус онлайна, правильные ответы, выученные слова, самостоятельные ответы.
    - Фиолетовый (`#8A78ED`): путешествия, грамматические подсказки.
    - Тёплый янтарь (`#E8AD53`): ответы с подсказкой, предупреждения, рекомендации.
    - Коралловый / Бордовый (`#DC6572`): ошибки, зона удаления данных.
- **Типографика:**
  - Гарнитура `Inter` (Google Fonts), начертания 400 (текст), 600 (акценты), 700 (заголовки), 800 (бренд и цифры).

### 3.2. Информационная архитектура (7 ключевых экранов)
1. **Глобальный Topbar:** Кнопка бургер-меню, центрированный бренд-логотип `LinguaBot`, индикатор соединения (`● Онлайн`), аватар текущего пользователя.
2. **Экран «Сегодня» (Today):** Главный экран. Содержит блок быстрого старта диалога, чек-лист «План дня» из 4 шагов на 5–15 минут, карточку персональной рекомендации «Рекомендуем повторить» и интерактивный тест уровня из 3 вопросов.
3. **Экран «Диалоги» (Catalog):** Каталог 10 карточек жизненных сценариев с поиском, фильтрацией по категориям (Повседневное, Путешествия, Работа) и чипом текущего уровня сложности.
4. **Окно «Чат-тренажёр» (Chat):** Интерактивная беседа с ботом. Гибридный ввод: поле текста, микрофон с предпросмотром/правкой транскрипции ASR, кнопка «💡 Подсказка», аудиоплеер с повторной озвучкой реплик бота, клик по любому слову для вызова словарного перевода, кнопка «🏁 Завершить диалог».
5. **Экран «Практика» (Practice):** Адаптивные упражнения 3 типов (грамматика, лексика, аудирование) с мгновенной проверкой и подраздел офлайн-заданий.
6. **Экран «Словарь» (Dictionary):** Личный список слов с транскрипцией и контекстным примером + интерактивный 3D-тренажер карточек по алгоритму интервального повторения (SRS).
7. **Экран «Прогресс» (Progress):** Дашборд со счетчиками (streak, темы, слова), шкалой «Самостоятельно vs Подсказка» и галереей достижений.
8. **Экран «Профиль» (Profile):** Разработан строго по предоставленному эскизу: панель навигации BACK / EDIT, блок аватара и учетных данных, формы редактирования, переключатель ежедневных напоминаний (opt-in), секция STATS с пятиугольным Radar Chart по навыкам и Danger-зона (удаление истории и аккаунта).
