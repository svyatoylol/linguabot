## 🚀 О проекте

**«LinguaBot»** — это полнофункциональное кроссплатформенное веб-приложение (Progressive Web App, PWA), созданное для преодоления языкового барьера, снятия тревожности и развития навыков спонтанной разговорной речи на иностранных языках.

В отличие от традиционных тренажёров с пассивным заучиванием фраз, LinguaBot объединяет в единый цикл:
1. **Диалоговую практику** на 3 языках (английский, испанский, русский) по 10 жизненным и деловым сценариям.
2. **Мягкую обратную связь без перебивания** во время ответа с мгновенным разбором до 3 ключевых ошибок и понятными правилами.
3. **Режим «Без заготовки» (Ключевое УТП)** — принудительный перенос разобранного правила в новую спонтанную формулировку.
4. **Адаптивные упражнения** 3 типов (грамматика, лексика, аудирование) по реальным ошибкам пользователя.
5. **Личный словарь с интервальным повторением (SRS)** и 3D-тренажёром флеш-карточек.
6. **Честный учёт самостоятельности** — раздельный подсчёт ответов своими словами и ответов с подсказкой.

## 🛠 Технологический стек

- **Backend:** C# / .NET 8 (ASP.NET Core Minimal APIs, WebSockets, Entity Framework Core 8).
- **База данных:** PostgreSQL 18 (ApplicationDbContext + миграции) с отказоустойчивым ядром `LinguaDataStore` для автономной работы и демо-режима без запущенного сервера СУБД.
- **Диалоговый ИИ-движок:** Google Gemini API (`gemini-3.8-flash` / `gemini-3.5-flash-lite`) с гибридным контекстным генератором `IntelligentLanguageEngine` (время отклика **≤ 3 секунд**).
- **Речевые технологии (ASR / TTS):** Groq Whisper Large v3 (распознавание речи), Piper TTS ONNX и встроенный Web Speech API браузера для мгновенной озвучки и правки расшифровки перед отправкой.
- **Frontend / PWA:** Семантический HTML5, чистый CSS3 с дизайн-системой (по эскизу и UI/UX-макетам Figma), Vanilla JavaScript (ES2024), Service Worker для офлайн-режима базовых упражнений и словаря.

## ⚡ Запуск и развертывание

### 1. Локальный запуск через .NET CLI
В корне проекта выполните:

```powershell
dotnet run --project WebApplication1/WebApplication1
```

Приложение запустится и будет доступно по адресу:  
👉 **`http://localhost:5000`** (или указанному в консоли порту).

### 2. Запуск в Docker (Рекомендуемый для сервера)
```bash
cp .env.example .env
docker compose up -d --build
```
Подробная инструкция по настройке systemd, Nginx и Let's Encrypt SSL:  
📖 **[Инструкция по установке на сервер (docs/SERVER_DEPLOYMENT_GUIDE.md)](docs/SERVER_DEPLOYMENT_GUIDE.md)**
